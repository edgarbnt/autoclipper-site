# autoclipper-site

Public pages of AutoClipper (TikTok app requirements), served by GitHub Pages:

- `index.html` — what the tool is and how it uses TikTok
- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `callback.html` — OAuth redirect page: shows the TikTok authorization code to copy (stores nothing)

Source of truth: the `site/` folder of the private AutoClipper repository.
